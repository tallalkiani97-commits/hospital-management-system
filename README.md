# Hospital Management System

A clean frontend starter for hospital workflow management. It focuses on readable patient records, appointments and operational status cards.

## Included

- Patient registration form
- Appointment status dashboard
- Responsive layout
- No backend or real patient data

## Run

Open `index.html` in a browser or serve the folder:

```bash
python3 -m http.server 8000
```

## Stack

HTML · CSS · Vanilla JavaScript

> Demo only: never enter real patient data into this static prototype.
